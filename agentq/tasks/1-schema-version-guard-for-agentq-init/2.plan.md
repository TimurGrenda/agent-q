# Task 2: Add schema-version logic to agentq-init.ts

**Plan**: 1-schema-version-guard-for-agentq-init
**Status**: Pending
**Depends on**: Task 1

## Goal

Modify `agentq-init.ts` to read the source schema-version, compare it against the installed schema-version in meta.json, and either proceed or error.

## Context

- `agentq-init.ts` is the bootstrapper (202 lines)
- Section 1 (lines 41-50): reads source deno.json for version
- Section 2 (lines 53-88): creates/updates meta.json
- Section 3 (lines 95-131): copies scripts (always overwrites)
- After Task 1, `schema-version` file exists at repo root and `MetaData` has `schemaVersion?: number`

## Implementation

**File**: `agentq-init.ts`
**Action**: modify

### In section 1 (after reading deno.json, ~line 50):

Add reading of the schema-version file:
```typescript
const sourceSchemaVersion = parseInt(
  (await Deno.readTextFile(`${sourceDir}/schema-version`)).trim(),
  10,
);
if (isNaN(sourceSchemaVersion)) {
  throw new Error("schema-version file is missing or not a valid integer");
}
```

### In section 2 (after loading/creating meta, before writing meta.json):

Add schema-version comparison logic between the existing `stateStatus` check and the `meta.initVersion` stamp:

```typescript
// Schema-version guard: refuse to overwrite scripts if state format has changed.
// Legacy installs (no schemaVersion in meta.json) are treated as version 1.
if (stateStatus === "exists") {
  const installedSchema = (meta as Record<string, unknown>).schemaVersion as number | undefined ?? 1;
  if (installedSchema !== sourceSchemaVersion) {
    throw new Error(
      `Schema version mismatch: installed state is v${installedSchema}, ` +
      `source is v${sourceSchemaVersion}. ` +
      `Back up agentq/, remove it, and re-run agentq-init.`
    );
  }
}
meta.schemaVersion = sourceSchemaVersion;
```

Note: `stateStatus === "exists"` means meta.json existed before this run (not a fresh install). For fresh installs (`stateStatus === "created"`), we just stamp the version without comparing.
